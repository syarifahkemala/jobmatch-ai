# JobMatch AI

* This project allows me to develop and improve my skills as an AI Engineer.

* The purpose of this project is to build an AI-powered system that helps companies filter candidates based on the available job roles and their requirements.

* The system provides recommendations on which job roles are most suitable for a candidate based on their CV.

* The dataset used to train this project is from **Kaggle**:
  https://www.kaggle.com/datasets/snehaanbhawal/resume-dataset?resource=download-directory

* The dataset containing company roles and required skills consists of dummy data generated with AI. The required skills are mostly based on general skills commonly associated with each role.
